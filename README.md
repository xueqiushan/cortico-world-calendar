# 共享日历（cortico-world-calendar）

一个 Coopanion 的 World 插件 + 一个桌面日历窗口。
**你和她共用同一份日历**：你在窗口里改的她看得到，她加的你抬眼就能看到。
快到期时她提醒你，到期当晚她问你完成得怎么样。

---

## 它长什么样

桌面上一个独立窗口（Edge「安装为应用」），**普通窗口**——不置顶、不抢焦点、能最小化，
不干扰你干活。

```
┌─────────────────────────────┬──────────────┐
│  2026 年 11 月               │  详情         │
│  日 一 二 三 四 五 六         │ 🔴 交论文初稿  │
│        1  2  3  4  5  6      │ 日期 11-05    │
│        🔴交论文              │ 备注 …        │
│  7  8  9 10 11 12 13         │ 感受 …        │
│            🎉双十一 🎂妈妈生日 │              │
│  …                          │              │
└─────────────────────────────┴──────────────┘
```

## 图标规则

| 图标 | 类型 | 说明 |
|---|---|---|
| 🔴 | 紧急截止 | 提前提醒（默认剩 7/3/1 天） |
| 🔵 | 普通日程 | 同上 |
| 🎂 | 生日 | 每年重复，**默认只在当天提醒** |
| 💕 | 纪念日 | 同上 |
| 🎉 | 节日 | 同上。**想过什么节自己加，不按法定节假日** |
| ✅ | — | 已完成（淡化但保留，翻日历能看见自己做过什么） |

## 安装

### 1. 插件部分

把整个文件夹放进 Coopanion（World 总览 → 安装本地扩展），选 `cortico-world-calendar` 这一层，**重启 Coopanion**。

> 不用 `npm install`。Cortico 直接加载 TypeScript 源码，不编译。

### 2. 桌面窗口部分

双击 `web\start.bat`。

会看到一个黑窗口，里面写着类似：

```
在 Edge 打开：http://127.0.0.1:8787/
```

**别关这个黑窗口**——关了服务就停了。

### 3. 装成独立窗口

Edge 打开上面那个地址 → 右上角菜单（…）→ **应用** → **将此站点安装为应用**。

装完任务栏会有个图标，右键「锁定到任务栏」。以后点一下就开，**关了也能重开**，数据在文件里不会丢。

### 4. 开机自启（可选）

`Win+R` → 输入 `shell:startup` → 把 `web\start.bat` 的快捷方式放进去。

## 配置项（Coopanion 界面里改）

| 配置 | 默认 | 说明 |
|---|---|---|
| 提前提醒（天） | `7,3,1` | 想只要 3 天和 1 天就写 `3,1`；加 14 天写 `14,7,3,1`；留空则不提前提醒 |
| 到期当天询问 | 开 | 到期当天问你「完成得怎么样」 |
| 询问时刻（点） | `20` | 晚上八点。白天问你还没做完，晚上问才有意义 |
| 扫描间隔（分钟） | `5` | 改完要重启这个 World |
| 生日/节日也提前提醒 | 关 | 默认生日只在当天响一句 |

## 数据存在哪

`web\calendar.json`。**这是唯一真源**，两边都读写它。

- 两边写入都是**原子替换**（写临时文件再改名），不会读出半截文件
- 每次写入递增**版本号**
- 改完通过 SSE 立刻推送，对方自动刷新

想备份就复制这个文件。

---

## 三个必须知道的代价

**① Coopanion 关了，她就不提醒**

提醒是插件推的，插件跑在 Coopanion 进程里。
所以桌面窗口做了**浏览器通知兜底**：不管 Coopanion 开不开，今天/明天到期的日程都会弹桌面通知。
她在时是她关心你，她不在时至少不误事。

（第一次要点一下页面上的「开启桌面提醒」授权。）

**② 格子容量有限**

月历格子大约放得下 **30–40 字**（图标 + 标题 + 一行短备注），超出截断。
**想写长感受，点开右边详情面板**，不限字数。

**③ 同时改会覆盖**

同一条你和她同时改，后写的赢。有 `updatedAt` / `updatedBy`，能看出是谁改的。
个人使用频率下够用，没做真正的冲突合并。

---

## 关于「感受」

这个字段是你和她都能写的：**她能读到你写的，也能帮你记下你说过的话**。

但她被明确约束：**不能替你编造感受**。你没说过的，她不会代你感受。
如果感受栏里渐渐全是她的代笔，这个字段就失去意义了——它本该是你的心情。

右边详情面板会显示「最后修改：我 / 她」，哪段是她记的一眼能看出来。

---

## 未完成怎么办

**她不会擅自改期。** 到期没完成就是没完成，不是"挪到明天"——改不改是你决定的事，
她可以问，但不能替你改。

---

## token 开销

固定开销（环境提示词 + 工具声明）约 **1400–1800 token**，与触感插件相近。

控制措施：
- `calendar_list` **默认不带感受**（那是主要花销），需要时她才单读某一条
- 提醒事件里自动附带那条日程的感受，她说「你上次说写得很顺，今天呢」**不用额外调工具**
- 提示词里明确约束她**不要每次对话都翻日历**

## 目录结构

```
cortico-world-calendar/
├─ package.json          插件声明（main 指向 src/index.ts，不编译）
├─ describe.json         工具/事件/提示词静态清单（由 scripts/gen-describe.mjs 生成）
├─ src/                  插件源码
│   ├─ index.ts
│   ├─ definition.ts
│   ├─ config.ts         配置段与界面表单
│   ├─ store.ts          calendar.json 读写（原子写、版本号、日期计算）
│   ├─ world.ts          工具实现 + 定时提醒扫描
│   └─ ENV_PROMPT.md     给她的环境提示词
├─ web/
│   ├─ calendar.html     桌面窗口
│   ├─ server.mjs        本地小服务（Node 内置模块，零依赖）
│   ├─ start.bat         启动脚本
│   └─ calendar.json     数据（首次运行自动生成）
├─ typecheck/stubs/      仅本地类型自检用的 cortico 桩，不参与运行
└─ scripts/gen-describe.mjs
```

## 为什么需要一个本地服务

因为 `file://` 下浏览器读本地文件会被 Chromium 直接拒绝，那不是加响应头能解决的。
所以网页必须有个 http 源。

它只监听 `127.0.0.1`，不接受跨 origin，只用 Node 内置模块，零第三方依赖。

## 排错

| 现象 | 原因 / 怎么办 |
|---|---|
| 页面显示「服务未运行」 | `start.bat` 那个黑窗口被关了，重新双击 |
| 端口被占 | 服务会自动试 8787→8791；如果都占着会明确报错 |
| 她不知道有日历 | 检查 World 配置页里「共享日历 · 环境提示词」是否启用 |
| 改了配置没生效 | 扫描间隔改完要重启 World；提醒天数是即时生效的 |
| 通知不弹 | 点页面上的「开启桌面提醒」授权；Edge 设置里别屏蔽该站点通知 |
